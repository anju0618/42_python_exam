py_word_split  [Medium]

Assignment
Return True if `s` can be split into a sequence of one or more words
from `words`. A word may be used any number of times.
An empty `s` returns True.

Function signature
def word_split(s: str, words: list[str]) -> bool:

Examples
Input
word_split("leetcode", ["leet", "code"])
Output
True
Input
word_split("applepenapple", ["apple", "pen"])
Output
True
Input
word_split("catsandog", ["cats", "dog", "sand", "and", "cat"])
Output
False

---------- 和訳 ----------
課題
`s` を `words` の単語の並びに分割できれば True。同じ単語を何回使ってもよい。
`s` が空文字なら True。
