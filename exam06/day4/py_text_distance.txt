py_text_distance  [Hard]

Assignment
Return the minimum number of operations to turn string `a` into string
`b`. One operation is: insert a character, delete a character, or replace
a character.

Function signature
def text_distance(a: str, b: str) -> int:

Examples
Input
text_distance("horse", "ros")
Output
3
Input
text_distance("intention", "execution")
Output
5
