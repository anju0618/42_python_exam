py_coin_min  [Medium]

Assignment
Return the fewest coins needed to make exactly `amount`. Each coin value
can be used any number of times. Return -1 if it is impossible.
amount = 0 needs 0 coins.

Function signature
def coin_min(coins: list[int], amount: int) -> int:

Examples
Input
coin_min([1,2,5], 11)
Output
3
Input
coin_min([2], 3)
Output
-1
Input
coin_min([1], 0)
Output
0

---------- 和訳 ----------
課題
ちょうど `amount` を作るのに必要な最小の枚数を返す。各コインは何枚でも使える。
作れなければ -1。amount = 0 なら 0 枚。
