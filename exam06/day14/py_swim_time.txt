py_swim_time  [Hard]

Assignment
`grid` is an n x n square; grid[i][j] is the platform height. The water
level at time t is t. You may swim from a cell to a 4-neighbour only if BOTH
cells have height <= t. You start at the top-left cell at time 0 (you may
wait). Return the least time t at which you can reach the bottom-right cell.
All heights are different and between 0 and n*n - 1.

Function signature
def swim_time(grid: list[list[int]]) -> int:

Examples
Input
swim_time([[0,2],[1,3]])
Output
3
Input
swim_time([[0,1,2,3,4],[24,23,22,21,5],[12,13,14,15,16],[11,17,18,19,20],[10,9,8,7,6]])
Output
16

---------- 和訳 ----------
課題
`grid` は n×n。grid[i][j] は足場の高さ。時刻 t の水位は t。隣り合う(上下左右)2つのセルは、
「両方」の高さが t 以下のときだけ泳いで移動できる。時刻 0 に左上から出発(待ってよい)。
右下に着ける最小の時刻 t を返す。高さは 0〜n*n-1 で全て異なる。
