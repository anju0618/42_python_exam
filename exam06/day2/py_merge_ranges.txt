py_merge_ranges  [Medium]

Assignment
Merge all overlapping ranges [start, end] (inclusive). Ranges that only
touch (e.g. [1,4] and [4,5]) are also merged.
Return the merged ranges sorted by start. The input is not sorted.
(Do not use sorted() or .sort(): write your own sort.)

Function signature
def merge_ranges(ranges: list[list[int]]) -> list[list[int]]:

Examples
Input
merge_ranges([[1,3],[2,6],[8,10],[15,18]])
Output
[[1, 6], [8, 10], [15, 18]]
Input
merge_ranges([[1,4],[4,5]])
Output
[[1, 5]]

---------- 和訳 ----------
課題
範囲 [start, end](両端を含む)のうち重なるものをすべて統合する。端が接するだけ
(例: [1,4] と [4,5])でも統合する。結果は start の昇順。入力は整列されていない。
(sorted() や .sort() は使わず、自作のソートで)
