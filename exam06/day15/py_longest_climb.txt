py_longest_climb  [Hard]

Assignment
Return the length of the longest strictly increasing path in the matrix.
From a cell you can move up, down, left or right (no diagonals, no leaving
the matrix). The matrix is not empty.
Hint: DFS with memoization.

Function signature

Examples
Input
longest_climb([[9,9,4],[6,6,8],[2,1,1]])
Output

Input

Output
4
