py_redundant_link  [Medium]

Assignment
`edges` describes an undirected graph that started as a tree with nodes
labeled 1..n, then ONE extra edge was added (so it now contains exactly one
cycle). Return an edge that can be removed so that the graph becomes a tree
again. If several edges qualify, return the one that appears LAST in `edges`.

Function signature
def redundant_link(edges: list[list[int]]) -> list[int]:

Examples
Input
redundant_link([[1,2],[1,3],[2,3]])
Output
[2, 3]
Input
redundant_link([[1,2],[2,3],[3,4],[1,4],[1,5]])
Output
[1, 4]

---------- 和訳 ----------
課題
`edges` は、ノード 1〜n の木に辺を「1本だけ」足した無向グラフ(サイクルがちょうど1つ)。
取り除くと再び木になる辺を返す。候補が複数あるときは `edges` の中で一番最後に出てくるもの。

関数シグネチャ
def redundant_link(edges: list[list[int]]) -> list[int]:
