py_array_rotation_detector

Assignment
Write a function that takes two lists as parameters and determines if
the second list is a rotation of the first list (left or right).
A rotation means the elements are shifted circularly. If the arrays have
different lengths, they cannot be rotations of each other. Two empty
arrays are considered rotations of each other.

Function signature
def array_rotation_detector(arr1: list, arr2: list) -> bool:

Examples
Input
array_rotation_detector([1, 2, 3, 4, 5], [4, 5, 1, 2, 3])
Output
True
Input
array_rotation_detector([1, 2, 3, 4, 5], [5, 1, 2, 3, 4])
Output
True
Input
array_rotation_detector([1, 2, 3], [3, 2, 1])
Output
False
Input
array_rotation_detector([1, 2], [1, 2, 3])
Output
False
Input
array_rotation_detector([], [])
Output
True
