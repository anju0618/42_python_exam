py_sliding_window_maximium

Assignment
Given a list of integers nums and an integer k, consider a window of
size k sliding from left to right, one position at a time. For each
window position, find the maximum value within it. Return the list of
all these maximum values, in order.

Constraints:
- If nums is empty or k <= 0, return [].
- The number of windows is len(nums) - k + 1.

Function signature
def sliding_window_maximium(nums: list[int], k: int) -> list[int]:

Examples
Input
sliding_window_maximium([1, 3, -1, -3, 5, 3, 6, 7], 3)
Output
[3, 3, 5, 5, 6, 7]
Input
sliding_window_maximium([4, 2, 12, 11, -5], 2)
Output
[4, 12, 12, 11]
Input
sliding_window_maximium([], 3)
Output
[]
