lc057_insert_interval
Based on: LeetCode 57. Insert Interval

Assignment (paraphrased)
Given a list of non-overlapping intervals sorted by start value, and a
new interval, insert it (merging overlaps as needed) so the result
stays sorted and non-overlapping.

Function signature
def insert(intervals: list[list[int]], new_interval: list[int]) -> list[list[int]]:

Examples
Input
insert([[1,3],[6,9]], [2,5])
Output
[[1,5],[6,9]]
Input
insert([[1,2],[3,5],[6,7],[8,10],[12,16]], [4,8])
Output
[[1,2],[3,10],[12,16]]
