Assignment (paraphrased)
Given an array of 2D points and an integer k, return the k points
closest to the origin (Euclidean distance). Any order is acceptable;
the answer set is guaranteed unique.

Function signature
def k_closest(points: list[list[int]], k: int) -> list[list[int]]:

Examples
Input
k_closest([[1,3],[-2,2]], 1)
Output (order doesn't matter)
[[-2,2]]
Input
k_closest([[3,3],[5,-1],[-2,4]], 2)
Output
[[3,3],[-2,4]]
