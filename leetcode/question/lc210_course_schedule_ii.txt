Assignment (paraphrased)
There are n courses labeled 0..n-1. Some courses have prerequisites,
given as a list of [course, prerequisite] pairs. Return one valid order
to take all courses, or an empty list if it is impossible (a cycle
exists).

Function signature (adapted here to use names instead of numeric ids,
matching the exam version)
def course_order(courses: dict[str, list[str]]) -> list[str]:

Examples
Input
course_order({"app": ["database"], "database": ["driver"], "driver": []})
Output
["driver", "database", "app"]
Input
course_order({"X": ["Y"], "Y": ["X"]})
Output
[]
