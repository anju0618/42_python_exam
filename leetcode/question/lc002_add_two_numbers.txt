lc002_add_two_numbers
Based on: LeetCode 2. Add Two Numbers

Assignment (paraphrased)
Two non-negative integers are given as linked lists, digits stored in
reverse order (least significant digit first), one digit per node.
Add the two numbers and return the sum as a linked list in the same
reversed-digit format.
