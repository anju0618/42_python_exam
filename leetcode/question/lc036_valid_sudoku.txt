Assignment (paraphrased)
Given a 9x9 Sudoku board (partially filled, '.' for empty cells),
determine whether the filled cells make it valid so far: each row,
each column, and each of the nine 3x3 sub-boxes must not contain the
same digit (1-9) twice. The board does not need to be solvable, only
consistent with these rules.
