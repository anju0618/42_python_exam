lc739_daily_temperatures
Based on: LeetCode 739. Daily Temperatures

Assignment (paraphrased)
Given a list of daily temperatures, return a list answer such that
answer[i] is the number of days you'd have to wait after day i to see
a strictly warmer temperature. If there's no such future day, use 0.

Function signature
def daily_temperatures(temperatures: list[int]) -> list[int]:

Examples
Input
daily_temperatures([73,74,75,71,69,72,76,73])
Output
[1,1,4,2,1,1,0,0]
Input
daily_temperatures([30,40,50,60])
Output
[1,1,1,0]
Input
daily_temperatures([30,60,90])
Output
[1,1,0]
