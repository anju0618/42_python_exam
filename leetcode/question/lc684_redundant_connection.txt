Based on: LeetCode 684. Redundant Connection

Assignment (paraphrased)
A tree of n nodes (labeled 1..n) had exactly one extra edge added,
creating a cycle. Given the edges array, return the edge that can be
removed to make it a tree again. If several edges qualify, return the
one that appears last in the input.

Function signature
def find_redundant_connection(edges: list[list[int]]) -> list[int]:

Examples
Input
find_redundant_connection([[1,2],[1,3],[2,3]])
Output
[2,3]
Input
find_redundant_connection([[1,2],[2,3],[3,4],[1,4],[1,5]])
Output
[1,4]
