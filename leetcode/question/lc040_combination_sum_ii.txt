Based on: LeetCode 40. Combination Sum II

Assignment (paraphrased)
Given a list of candidate numbers (which may contain duplicates) and a
target, find all unique combinations that sum to target. Each number
may be used at most once (once per occurrence in the input). No
duplicate combinations in the result.

Function signature
def combination_sum2(candidates: list[int], target: int) -> list[list[int]]:

Examples
Input
combination_sum2([10,1,2,7,6,1,5], 8)
Output (order doesn't matter)
[[1,1,6],[1,2,5],[1,7],[2,6]]
Input
combination_sum2([2,5,2,1,2], 5)
Output
[[1,2,2],[5]]
