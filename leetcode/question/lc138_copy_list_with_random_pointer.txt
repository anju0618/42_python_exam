Assignment (paraphrased)
Each node of a linked list has a next pointer and a random pointer
(which may point to any node in the list, or be None). Return a deep
copy of the list: same structure, but made of entirely new nodes.

class Node:

Examples
Input
a 3-node list where node0.random -> node2, node1.random -> node1,
node2.random -> node0
Output
a deep copy with the same val/next/random structure, but no node
shared with the original list
