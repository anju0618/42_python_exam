Assignment (paraphrased)
Design an algorithm to encode a list of strings into a single string,
and a matching decode function that turns that single string back into
the original list of strings. Strings may contain any characters
(including the delimiter you choose to use), so a naive
join-with-a-separator approach is not safe.

Function signatures
def encode(strs: list[str]) -> str:
def decode(s: str) -> list[str]:

Examples
Input
decode(encode(["lint","code","love","you"]))
Output
["lint","code","love","you"]
Input
decode(encode(["we","say",":","yes"]))
Output
["we","say",":","yes"]
Input
decode(encode([]))
Output
[]
