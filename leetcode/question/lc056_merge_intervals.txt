Assignment (paraphrased)
Given an array of intervals (not necessarily sorted), merge all
overlapping intervals and return the resulting non-overlapping
intervals covering the same ranges.

Function signature
def merge(intervals: list[list[int]]) -> list[list[int]]:

Examples
Input

Output
[[1,6],[8,10],[15,18]]

merge([[1,4],[4,5]])

[[1,5]]
