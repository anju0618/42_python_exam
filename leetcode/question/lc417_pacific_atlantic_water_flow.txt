lc417_pacific_atlantic_water_flow
Based on: LeetCode 417. Pacific Atlantic Water Flow

Assignment (paraphrased)
An island's heights grid borders the Pacific on its left/top edges and
the Atlantic on its right/bottom edges. Water flows from a cell to a
4-directional neighbor only if the neighbor's height is <= the
current cell's height. Return every cell from which water can reach
both oceans. Order of the result doesn't matter.

Function signature
def pacific_atlantic(heights: list[list[int]]) -> list[list[int]]:

Examples
Input
pacific_atlantic([[1,2,2,3,5],[3,2,3,4,4],[2,4,5,3,1],[6,7,1,4,5],[5,1,1,2,4]])
Output (order doesn't matter)
[[0,4],[1,3],[1,4],[2,2],[3,0],[3,1],[4,0]]
Input
pacific_atlantic([[1]])
Output
[[0,0]]
