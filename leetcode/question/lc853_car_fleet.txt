lc853_car_fleet
Based on: LeetCode 853. Car Fleet

Assignment (paraphrased)
n cars sit at given positions on a road, all driving toward the same
target mile. position[i] and speed[i] give car i's starting mile and
speed. A car cannot pass another; if it catches up to a slower one
ahead, it continues at that car's speed as part of the same fleet.
Return the number of distinct fleets that arrive at target.

Function signature
def car_fleet(target: int, position: list[int], speed: list[int]) -> int:

Examples
Input
car_fleet(12, [10,8,0,5,3], [2,4,1,1,3])
Output
3
Input
car_fleet(10, [3], [3])
Output
1
Input
car_fleet(100, [0,2,4], [4,2,1])
Output
1
