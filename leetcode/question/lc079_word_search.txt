Assignment (paraphrased)
Given an m x n grid of characters and a word, return True if the word
can be formed by a path of horizontally/vertically adjacent cells,
without reusing the same cell twice.

Input
exist([["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], "ABCCED")
Output
True
Input
exist([["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], "ABCB")
