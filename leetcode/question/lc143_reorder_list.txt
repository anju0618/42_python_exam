Assignment (paraphrased)
Given the head of a singly linked list L0 -> L1 -> ... -> Ln, reorder
it in place to L0 -> Ln -> L1 -> Ln-1 -> L2 -> Ln-2 -> ... Only node
links may change, not the values. Returns nothing (modifies in place).
