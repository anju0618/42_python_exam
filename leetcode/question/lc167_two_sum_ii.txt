lc167_two_sum_ii
Based on: LeetCode 167. Two Sum II - Input Array Is Sorted

Assignment (paraphrased)
Given a 1-indexed array already sorted in non-decreasing order, find
two numbers that add up to target. Return their indices (1-indexed) as
[index1, index2] with index1 < index2. Exactly one solution exists, the
same element can't be used twice, and only constant extra space is
allowed.

Function signature
def two_sum_sorted(numbers: list[int], target: int) -> list[int]:

Examples
Input
two_sum_sorted([2,7,11,15], 9)
Output
[1,2]
Input
two_sum_sorted([2,3,4], 6)
Output
[1,3]
Input
two_sum_sorted([-1,0], -1)
Output
[1,2]
