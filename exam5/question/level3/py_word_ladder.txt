py_word_ladder

Assignment
Write a function that computes the length of the shortest
transformation sequence from a `start` word to an `end` word using a
dictionary list of allowed words `sentence`.

Each transformation step must change exactly one single character. All
intermediate words must exist in `sentence`.

The function should:
- Return the total number of words in the shortest ladder (including
  `start` and `end`).
- Return 0 if no transformation sequence is possible.

Function signature
def word_ladder(start: str, end: str, sentence: list[str]) -> int:

Examples
Input
word_ladder("hit", "cog", ["hot", "dot", "dog", "lot", "log", "cog"])
Output
5
Input
word_ladder("hit", "cog", ["hot", "dot", "dog", "lot", "log"])
Output
0

Similar to (probably): LeetCode 127. Word Ladder (identical problem,
just renamed parameters: begin_word/end_word/word_list here are
start/end/sentence).
Reference: question/leetcode/lc127_word_ladder.txt

---------- 和訳 ----------
課題
許可された単語のリスト `sentence` を使って、`start` の単語から `end` の単語への
最短の変換列の長さを求める関数を書きなさい。

各変換ステップでは、ちょうど1文字だけを変更しなければならない。途中の単語はすべて
`sentence` に含まれていなければならない。

関数は次のようにすること:
- 最短のラダーに含まれる単語の総数(`start` と `end` を含む)を返す。
- 変換列が不可能なら 0 を返す。

def word_ladder(start: str, end: str, sentence: list[str]) -> int:
