py_prism_detector

Assignment
Write a function that searches for all occurrences of a target word
pattern within a 2D grid of characters in all 8 cardinal and diagonal
directions.

The directions and their codes are:
- (1, 0) -> "H" (Horizontal right)
- (-1, 0) -> "H-" (Horizontal left)
- (0, 1) -> "V" (Vertical down)
- (0, -1) -> "V-" (Vertical up)
- (1, 1) -> "D1" (Diagonal down-right)
- (-1, -1) -> "D1-" (Diagonal up-left)
- (-1, 1) -> "D2" (Diagonal up-right)
- (1, -1) -> "D2-" (Diagonal down-left)

The function should:
- Take a grid of strings `grid` and a target string `pattern`.
- Return a list of tuples (x, y, direction_code) for each match, where
  x is the column index and y is the row index of the first character.
- Return an empty list [] if either grid or pattern is empty.

Function signature
def prism_detector(grid: list[str], pattern: str):

Examples
Input
prism_detector(["CAT", "A..", "T.."], "CAT")
Output
[(0, 0, "H"), (0, 0, "V")]
Input
prism_detector([], "CAT")
Output
[]

Similar to (probably): LeetCode 79. Word Search (same grid-of-letters
setup, but LC79 only checks 4-directional adjacency without reuse and
returns a single bool, while this one scans all 8 directions and
returns every match with its direction code -- closer in spirit to a
classic word-search-puzzle solver).

課題
文字の2次元グリッドの中から、対象の単語パターンの出現をすべて、縦・横・斜めの8方向で
探索する関数を書きなさい。

方向とそのコードは次の通り:
- (1, 0) -> "H" (水平・右向き)
- (-1, 0) -> "H-" (水平・左向き)
- (0, 1) -> "V" (垂直・下向き)
- (0, -1) -> "V-" (垂直・上向き)
- (1, 1) -> "D1" (斜め・右下)
- (-1, -1) -> "D1-" (斜め・左上)
- (-1, 1) -> "D2" (斜め・右上)
- (1, -1) -> "D2-" (斜め・左下)

関数は次のようにすること:
- 文字列のグリッド `grid` と対象の文字列 `pattern` を受け取る。
- 一致ごとにタプル (x, y, direction_code) を作り、そのリストを返す。x は先頭文字の列
  インデックス、y は行インデックス。
- grid または pattern が空なら空リスト [] を返す。

関数シグネチャ
def prism_detector(grid: list[str], pattern: str):
