py_schedule_meetings

Assignment
Write a function that determines the minimum number of meeting rooms
required to schedule a list of meeting time intervals without overlap,
and assigns meetings to rooms.

Each interval is represented as a tuple of (start_time, end_time).

The function should:
- Sort meetings by start time and assign them to available rooms
  sequentially.
- Return a tuple (num_rooms, rooms) where num_rooms is the integer
  count of rooms required, and rooms is a list of lists containing the
  scheduled intervals for each room.
- If the input list is empty, return (0, []).

Function signature
def schedule_meetings(intervals: list[tuple[int, int]]) -> tuple[int, list]:

Examples
Input
schedule_meetings([(0, 30), (5, 10), (15, 20)])
Output
(2, [[(0, 30)], [(5, 10), (15, 20)]])
Input
schedule_meetings([])
Output
(0, [])

Similar to (probably): LeetCode 253. Meeting Rooms II (same minimum-
room-count idea; this variant also returns which room each meeting was
assigned to, not just the count).
Reference: question/leetcode/lc253_meeting_rooms_ii.txt

---------- 和訳 ----------
課題
重ならないように会議の時間区間のリストをスケジュールするのに必要な最小の会議室数を求め、
各会議を会議室に割り当てる関数を書きなさい。

各区間は (開始時刻, 終了時刻) のタプルで表される。

関数は次のようにすること:
- 会議を開始時刻でソートし、空いている会議室へ順番に割り当てる。
- タプル (num_rooms, rooms) を返す。num_rooms は必要な会議室数(整数)、
  rooms は各会議室にスケジュールされた区間のリストからなるリスト。
- 入力リストが空なら (0, []) を返す。
