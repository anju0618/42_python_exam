py_graph_cycle_detector

Assignment
Write a function that determines whether a directed graph contains at
least one cycle.

The function takes a dictionary representing an adjacency list where
keys are integer node IDs and values are lists of integer neighbor
node IDs.

The function should:
- Return True if the directed graph contains a cycle.
- Return False if the graph is acyclic or if the input graph dictionary
  is empty.
- Correctly handle graphs with multiple disconnected components.

Forbidden built-ins / modules: graphlib.TopologicalSorter.
Implement the algorithm manually.

Function signature
def py_graph_cycle_detector(graph: dict[int, list[int]]) -> bool:

Examples
Input
py_graph_cycle_detector({0: [1], 1: [2], 2: [0]})
Output
True
Input
py_graph_cycle_detector({0: [1], 1: [2], 2: []})
Output
False
Input
py_graph_cycle_detector({})
Output
False

---------- 和訳 ----------
課題
有向グラフに少なくとも1つの閉路(サイクル)があるかを判定する関数を書きなさい。

関数は隣接リストを表す辞書を受け取る。キーは整数のノードID、値は隣接ノードIDの整数リスト。

関数は次のようにすること:
- 有向グラフに閉路があれば True を返す。
- グラフが非巡回、または入力の辞書が空なら False を返す。
- 複数の非連結成分を持つグラフも正しく扱う。

使用禁止の組み込み/モジュール: graphlib.TopologicalSorter。
アルゴリズムは自分で実装すること。
