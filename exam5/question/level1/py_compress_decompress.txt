py_compress_decompress

Assignment
Write two functions: compress and decompress.

compress(s: str) -> str:
- Takes a string and compresses consecutive repeated characters by
  appending the count after the character.
- If a character appears only once consecutively, omit the number '1'.
- If the input string is empty, return an empty string.

decompress(s: str) -> str:
- Takes a compressed string and expands it back to its uncompressed
  form.
- Handles multi-digit counts (e.g. "a12" -> 12 'a's).
- If no count follows a character, it counts as 1.

def compress(s: str) -> str:
def decompress(s: str) -> str:

Examples
Input
compress("aabcccccaaa")
Output
"a2bc5a3"
Input
decompress("a2bc5a3")
Output
"aabcccccaaa"
Input
compress("")
Output
""

---------- 和訳 ----------
課題
compress と decompress の2つの関数を書きなさい。

compress(s: str) -> str:
- 文字列を受け取り、連続して繰り返される文字を「文字+回数」の形に圧縮する。
- 連続して1回しか現れない文字には数字の '1' を付けない。
- 入力が空文字列なら空文字列を返す。

decompress(s: str) -> str:
- 圧縮された文字列を受け取り、元の形に展開する。
- 複数桁の回数に対応する (例: "a12" -> 'a' が12個)。
- 文字の後ろに回数がない場合は1回として扱う。
