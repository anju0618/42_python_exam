py_spiral_matrix

Assignment
Write a function that generates an n x n 2D matrix filled with numbers
from 1 to n^2 in clockwise spiral order.

The spiral starts at the top-left cell (0, 0) moving right, then down,
then left, then up, continuing inwards.

Function signature
def generate_spiral(n: int) -> list[list[int]]:

Examples
Input
generate_spiral(3)
Output
[[1, 2, 3], [8, 9, 4], [7, 6, 5]]
Input
generate_spiral(1)
Output
[[1]]

Similar to (probably): LeetCode 54. Spiral Matrix (same clockwise
spiral traversal order, but LC54 reads an existing matrix out in
spiral order while this one fills a fresh matrix with 1..n^2 in that
order -- that generating variant is LeetCode 59. Spiral Matrix II,
which isn't in this repo's leetcode/ set).
Reference: question/leetcode/lc054_spiral_matrix.txt

---------- 和訳 ----------
課題
1 から n^2 までの数を時計回りの渦巻き順に埋めた n x n の2次元行列を生成する関数を書きなさい。

渦巻きは左上のセル (0, 0) から始まり、右 → 下 → 左 → 上の順に進み、内側へ続けていく。

関数シグネチャ
def generate_spiral(n: int) -> list[list[int]]:

例
(上記の Examples 参照)
